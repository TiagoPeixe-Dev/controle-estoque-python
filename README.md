# Sistema de Controle de Estoque em Python

Este projeto foi desenvolvido para a disciplina **Development with Python**.

## Tecnologias utilizadas

- Python
- SQLite

## Funcionalidades

- Login de usuários
- Cadastro de produtos
- Listagem de produtos
- Entrada de estoque
- Saída de estoque
- Histórico de movimentações
- Edição de produtos
- Exclusão de produtos
- Cadastro de usuários

## Banco de dados

O sistema utiliza SQLite para armazenar:

- usuários
- produtos
- movimentações

## Execução do sistema

Para executar o sistema:

```bash
python main.py
